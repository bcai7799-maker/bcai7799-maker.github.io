Predicting Statin LDL-C Response with Machine Learning

Capstone
First-author manuscript · Kaiser GERA cohort (N ≈ 34,800) · R

Statin type and dose strongly shape how much a patient's LDL cholesterol drops — but can machine learning predict individual response better than traditional regression? I built the full pipeline to find out, using real-world EHR data from more than 34,000 statin initiators.

I assembled the analytic dataset from raw Kaiser extracts, engineered two predictor sets (a baseline clinical set and an expanded EHR set), and compared linear regression, random forest, and XGBoost on a held-out test set with cross-validation.

The finding: machine learning did not outperform linear regression. All models explained roughly 13% of the variance — matching the published benchmark for this cohort. A nested-R² analysis showed why: statin type and dose account for almost all the signal, and the relationship is close to linear, leaving little for ML to exploit.

Radiation Therapy & Tumor Laterality in Breast Cancer Survival

Survival analysis · METABRIC cohort (N = 1,981) · R

Does the survival benefit of radiation therapy depend on which side of the body the tumor is on? Left-sided breast tumors sit closer to the heart, raising long-standing concerns about radiation cardiotoxicity. I tested whether tumor laterality modifies the effect of radiation on overall survival.

Using the METABRIC cohort, I fit stratified Cox proportional hazards models with a radiation × laterality interaction term, handled ~30% non-random missingness with multiple imputation (MICE), and addressed proportional-hazards violations by stratifying on five covariates. I validated the model with bootstrap resampling.

Radiation was associated with a 31% reduction in the hazard of death (HR 0.69), and the benefit did not differ meaningfully by tumor side — reassuring evidence that modern radiation helps left- and right-sided patients alike.

boot_metric <- function(pred, obs, fn, R = 1000) {
  b <- boot(data.frame(pred, obs),
           function(d, i) fn(d[i, ]), R = R)
  boot.ci(b, type = "perc")$percent[4:5]
}
